## О проекте

**MP Analyzer** — гибридный инструмент для аналитики Wildberries, разработанный в рамках тестового задания.
Превосходит классические Google Apps Script решения: даёт веб-интерфейс, живые данные и Excel-отчёт одной кнопкой.

### Возможности

| Функция | Описание |
|---|---|
| 🔍 **Поиск WB** | Топ-100 товаров по любому запросу через API Wildberries |
| 📈 **Дашборд** | Обогащение данных аналитикой MPStats (выручка, упущенная прибыль, дни на сайте) |
| 🎨 **Условное форматирование** | 🟢 топ-5 по выручке, 🔴 убыточные, 🟡 перспективные новинки |
| 📥 **Экспорт в Excel** | Два листа (Выдача WB + Dashboard) с цветами |
| 📂 **Свой CSV** | Загрузите любой экспорт MPStats для своей ниши |

## Технологии

- **Python 3.10+** — основная логика
- **Streamlit** — интерактивный веб-интерфейс
- **pandas** — обработка и объединение данных
- **openpyxl** — генерация Excel с форматированием
- **curl_cffi** — обход WAF Wildberries (имитация TLS Chrome)
- **Wildberries API** — публичный эндпоинт поисковой выдачи

## Установка и запуск

```bash
# Клонировать репозиторий
git clone https://github.com/PavelMenshikov/MPAnalyzer.git
cd MPAnalyzer

# Установить зависимости
pip install -r requirements.txt

# Запустить приложение
streamlit run app.py
```

Приложение откроется в браузере по адресу `http://localhost:8501`.

## Как пользоваться

### Быстрый старт

1. Откройте приложение — слева загружен демо-файл (Проекторы, 307 товаров)
2. Введите поисковый запрос (например, **«проектор для фильмов»**) и нажмите **«Выполнить поиск»**
3. Перейдите на вкладку **«Dashboard»** — увидите цветную аналитику
4. Нажмите **«Скачать Excel»** — получите готовый отчёт

### Со своим CSV

1. В боковой панели нажмите **«Загрузить MPStats CSV»**
2. Выберите ваш файл (формат: CSV с разделителем `;`)
3. Введите поисковый запрос и работайте как обычно

> **Где взять CSV?** Экспорт из сервиса [MPStats](https://mpstats.ru) — выберите категорию, скачайте CSV, загрузите в приложение.

## Условное форматирование

| Цвет | Условие | Что означает |
|---|---|---|
| 🟢 Зелёный | Топ-5 по выручке (Revenue) | Самые прибыльные товары |
| 🔴 Красный | Lost profit > Revenue × 2 | Товары-убытки — требуют внимания |
| 🟡 Жёлтый | Days on site < 60 AND в топ-20 выдачи | Перспективные новинки |

## Формат сдачи

Инструмент поставляется в двух форматах:
1. **Веб-приложение** (Streamlit) — интерактивный дашборд
2. **Excel-файл** — скачивается одной кнопкой, готов к отправке
